# AuthorAgent v4.1.0 — 2026-08-07

**Status:** release candidate; not merged, tagged, or deployed
**Pull request:** [#15](https://github.com/dabeezor/AuthorAgent/pull/15)
**Work item:** ALP-5 / M2.3 comments anchoring

## What changes

- Adds review comments anchored either to a Markdown `##` section or a quoted
  span within that section.
- Adds endpoints to list/create comments and to resolve or reopen a comment.
- Carries open comments into revision prompts.
- Re-anchors spans after document revisions using exact then fuzzy matching;
  when a span or section disappears, the comment degrades to a section-level
  record rather than being silently deleted.

This is a backward-compatible feature addition, so the release increments the
minor version from `4.0.0` to `4.1.0`.

## Compatibility and data

- No existing schema or workspace migration is required.
- Comments are stored in
  `workspace/projects/<slug>/.versions/<stepId>/comments.json`.
- Existing projects without that file continue to behave as having no comments.
- The release changes revision prompt content when open comments exist; QA must
  verify that resolved comments are excluded.
